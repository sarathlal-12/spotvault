Your admin key

Approving changes your GitHub releases, so it needs a GitHub key only you have. The key is sent only to api.github.com. Without it you can still look around, but the buttons stay locked.

How do I get a key?
  1. Open GitHub → New fine-grained token.
  2. Name it SpotVault admin. Under Repository access pick Only select repositories → spotvault.
  3. Under Permissions → Repository → Contents choose Read and write. Nothing else.
  4. Click Generate token, copy it and paste it above.

How a new version goes out

  1. Build the Windows installer and publish the release on GitHub as a pre-release (it shows here as TESTING). Pushing the tag builds the Android and iPhone files and attaches them automatically.
  2. Install it yourself from the release page and test it. Users don't see it yet.
  3. Check the three files are listed below, edit the notes users will read, then press Approve & send to users.
  4. Something wrong after approving? Press Pull back. Apps stop offering it on their next check.
